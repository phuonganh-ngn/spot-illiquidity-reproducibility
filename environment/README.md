# Recorded software environments

The project used separate environments across stages. Their recorded package versions are preserved in the experiment output directories, including the Phase 6 package record and the external QML software record. Phase 13 and Phase 14 validation reports also record the Python and library versions used for their runs.

`requirements-report.txt` is only for the read-only result checks and figure rebuilding. It is not a substitute for the stage-specific model environments.
